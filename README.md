# ruimarques.xyz

Source for [ruimarques.xyz](https://ruimarques.xyz), Rui Marques’s personal
website and blog.

The site is generated by Hugo and deployed to Cloudflare Pages by GitHub
Actions. It contains one small first-party script for a system/light/dark theme
preference saved in `localStorage`, and no analytics or third-party runtime
dependencies. Page content lives in Markdown; protocol files and supplied
binary assets live under `static/`.

## Development

The repository uses a Nix flake and `direnv` for a reproducible toolchain.

```sh
direnv allow
just --list
just serve
just check
```

`just serve` includes drafts and future-dated posts. Production builds exclude
both.

## Content

Create a draft blog post with a lowercase, hyphenated slug:

```sh
just new-post compiler-notes
```

Posts live at `content/blog/YYYY-MM-DD-slug.md`. Set `draft: false` when a post
is ready; published posts require a short description. The blog feed publishes
the twenty newest posts in full at `/blog/index.xml`.

`content/cv.md` is the canonical HTML CV source. Replace `static/cv.pdf` with
the matching supplied artifact when the CV changes. This repository does not
generate the PDF. Refresh its review checksum before running the checks:

```sh
sha256sum static/cv.pdf > checksums/cv.pdf.sha256
just check
```

The social card and Apple touch icon are committed derivatives of their SVG
sources. Regenerate them reproducibly with `just assets`; `just check` rejects
stale copies.

The armored OpenPGP key is `static/pgp`; its direct-method WKD form is under
`static/.well-known/openpgpkey/`. If the key rotates, replace both forms, update
the pinned fingerprint in the contact page and key check, then run
`just check`.

Renew the `Expires` date in `static/.well-known/security.txt` during routine
maintenance. Checks require it to remain between thirty days and one year away.
The scheduled workflow checks this date and public outbound links each week.

## Deployment

The workflow expects a Cloudflare Pages Direct Upload project named
`ruimarques-xyz` and these GitHub production-environment secrets:

- `CLOUDFLARE_ACCOUNT_ID`
- `CLOUDFLARE_API_TOKEN`, scoped to edit this Pages project

Before switching traffic:

1. Deploy and validate the generated `pages.dev` URL.
2. Disable Email Address Obfuscation, Rocket Loader, Web Analytics, Zaraz, HTML
   minification, and other response transforms for this hostname. Remove any
   rule that adds the retired `Onion-Location` header.
3. Attach `ruimarques.xyz` as the custom domain without changing existing mail,
   CAA, or DNSSEC records.
4. Add a path- and query-preserving `www.ruimarques.xyz` redirect to the apex.
5. Redirect the production `pages.dev` hostname to the apex; previews remain
   marked `noindex` by `_headers`.
6. Keep managed AI-crawler blocking enabled and verify the served
   `Content-Signal` policy.
7. Verify HTTP-to-HTTPS routing and HTTPS on every hostname before retaining the
   one-year HSTS header.
8. Set the GitHub Actions repository variable `PRODUCTION_LIVE` to `true`, then
   run the Site workflow manually. This enables exact production smoke tests on
   deployments and during the weekly audit.

Pushes to `main` deploy only after all checks pass. Pull requests build and
validate without receiving deployment credentials. Smoke tests compare the
served bytes with the build output, so Cloudflare script injection, stale
content, redirects, and response transforms fail the deployment.
